# ศูนย์การกำหนดค่า

เรียก **DelendAI: Open Configuration Center** ใน VS Code และเลือกโปรเจกต์เมื่อมีหลาย root หน้าจอจะแสดงการตั้งค่าทั่วไป ปลั๊กอิน ผู้ให้บริการ เอเจนต์ สกิล พรอมต์ ทรัพยากร และความรู้ พร้อมเจ้าของและแหล่งที่มา

## การแก้ไขที่ปลอดภัย

ศูนย์จะแก้เฉพาะ `delendai.config.json` ส่วนคำสั่งเซิร์ฟเวอร์ อาร์กิวเมนต์ คำนำหน้า ธีม และภาษายังคงเป็นค่าของ VS Code การบันทึกตรวจ digest รวมเฉพาะพาธที่แก้ ตรวจเอกสารทั้งหมด และแทนไฟล์แบบ atomic ฟิลด์ที่ไม่รู้จักและเซิร์ฟเวอร์ภายนอกที่ปิดไว้จะไม่สูญหาย เมื่อขัดแย้งให้โหลดใหม่แล้วใช้การเปลี่ยนแปลงอีกครั้ง

ค่าลับถูกซ่อน และ `env` ใส่ได้เฉพาะชื่อ variable หลังแก้ไขให้รีสตาร์ทเซิร์ฟเวอร์

## ผู้เขียนปลั๊กอิน

ประกาศ `optionsSchema` ใน `definePlugin(...)` เดียวกับที่ตรวจ `ctx.options` และให้ `configExample.options` ผ่าน schema เดียวกัน ปลั๊กอิน local ผ่าน `plugins.<id>.path` และ MCP ภายนอกจะแสดง schema และที่มาอัตโนมัติ
