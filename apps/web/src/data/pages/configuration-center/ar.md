# مركز الإعدادات

شغّل **MCP Vertex: Open Configuration Center** في VS Code واختر المشروع في النوافذ متعددة الجذور. تعرض الأقسام الإعدادات العامة والإضافات والمزوّدين والوكلاء والمهارات والموجّهات والموارد والمعرفة مع المالك والمصدر.

## تعديل آمن

يُعدّل المركز `mcp-vertex.config.json` فقط؛ يبقى أمر الخادم ووسائطه وبادئته والسمة واللغة ضمن تفضيلات VS Code. يتحقق الحفظ من بصمة الملف ويدمج المسارات المعدلة فقط ويتحقق من المستند كاملًا ثم يستبدله ذريًا. تُحفظ الحقول غير المعروفة والخوادم الخارجية المعطلة. عند التعارض أعد التحميل ثم طبّق التغيير مجددًا.

تظل الأسرار مخفية، ويحتوي `env` أسماء المتغيرات فقط. أعد تشغيل الخادم بعد التغيير.

## مؤلفو الإضافات

انشر `optionsSchema` في `definePlugin(...)` نفسه الذي يتحقق من `ctx.options`، وحافظ على صلاحية `configExample.options`. تظهر الإضافات المحلية عبر `plugins.<id>.path` وأبناء MCP الخارجيون تلقائيًا مع المخطط والمصدر.
