# कॉन्फ़िगरेशन केंद्र

VS Code में **MCP Vertex: Open Configuration Center** चलाएँ और multi-root विंडो में प्रोजेक्ट चुनें। सामान्य सेटिंग, प्लगइन, प्रदाता, एजेंट, स्किल, प्रॉम्प्ट, संसाधन और ज्ञान अपने स्वामी और स्रोत के साथ दिखाई देते हैं।

## सुरक्षित संपादन

केवल `mcp-vertex.config.json` बदला जाता है; सर्वर कमांड, तर्क, प्रीफ़िक्स, थीम और भाषा VS Code की प्राथमिकताएँ रहती हैं। सेव फ़ाइल digest जाँचता है, केवल बदले पथ merge करता है, पूरा दस्तावेज़ validate करता है और फ़ाइल को atomic रूप से बदलता है। अज्ञात फ़ील्ड और बंद बाहरी सर्वर सुरक्षित रहते हैं। conflict पर reload करके बदलाव फिर लागू करें।

गुप्त मान छिपे रहते हैं; `env` में केवल variable names रखें। बदलाव के बाद सर्वर restart करें।

## प्लगइन लेखक

`ctx.options` को validate करने वाले `definePlugin(...)` में `optionsSchema` दें और `configExample.options` को उसी schema के अनुसार रखें। `plugins.<id>.path` वाले स्थानीय प्लगइन और बाहरी MCP बच्चे अपने schema और origin के साथ स्वतः दिखते हैं।
