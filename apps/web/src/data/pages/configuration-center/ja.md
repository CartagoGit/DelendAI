# 設定センター

VS Code で **MCP Vertex: Open Configuration Center** を実行し、マルチルートでは対象プロジェクトを選びます。一般設定、プラグイン、プロバイダー、エージェント、スキル、プロンプト、リソース、ナレッジとその所有元を確認できます。

## 安全な編集

変更するのは `mcp-vertex.config.json` だけです。起動コマンド、引数、プレフィックス、テーマ、言語は VS Code の設定に残ります。保存時はファイルのハッシュを確認し、変更したパスだけを結合し、文書全体を検証してアトミックに置換します。不明なフィールドや無効な外部サーバーも保持されます。競合時は再読み込みして変更を適用し直してください。

シークレットは非表示で、`env` には変数名だけを記述します。変更後はサーバーを再起動します。

## プラグイン作者

`ctx.options` を検証する `definePlugin(...)` に `optionsSchema` を公開し、`configExample.options` を同じスキーマに適合させます。`plugins.<id>.path` のローカルプラグインと外部 MCP の子は自動表示されます。
