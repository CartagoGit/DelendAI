## Hallazgos funcionales estáticos

**INT-OBS01 P2 — transporte autenticado duplica descarga y descarta límites.** `errors/list-errors.ts:144–167` hace webFetch sin auth sólo como preflight, luego fetch directo con auth y direct.text sin cap y retorna ok:true incluso HTTP401/500. Comentario142 dice engine no soporta headers pero web-fetch vigente sí (`fetch.interface.ts:43`). Los2 requests consumen cuota/tiempo, segundo cuerpo puede superar cap y fallo autenticación puede verse como [] por parser. `dispatchFetch` inyectado no envía `_headers` ni aplica allowList/cap, sólo señal. Corrección: único webFetch autenticado mediante seam existente, comprobar status y propagar truncación. Ninguna ejecución nueva.

**INT-OBS02 P2 — backend Datadog siempre devuelve colección vacía.** `index.ts:45–55` reconoce mapper no implementado pero registra descriptor con parseList()=>[]; tool sólo comprueba source/token, por tanto no alcanza 'actionable install hint' prometido47. Sentry builder además termina `/api/0/projects/` (`list-errors.ts:124`) mientras mapper sólo acepta envelope.data con issues. Se confirma desalineación fuente; compatibilidad exacta con API pública no probada ni consultada en esta tanda. Error JSON/malformed/blocked-host también se convierten en sin-incidentes. Debe devolver unavailable explícito por backend y validar fixture de API real antes de declarar integración estable.

**INT-OBS03 P2 — limit de 'recientes' selecciona archivos antiguos.** `traces/real-deps.ts:57–63` ordena filenames descendente, concatena records nuevos antes de antiguos (`loadLogs:219–223`), luego `takeRecent:101` toma cola. Dos archivos diarios hacen que limit pequeño elija el más antiguo. Specs110–119 sólo un archivo, no timestamps desordenados. Ordenar por ts y tomar últimos antes de agrupar. También grupos no incluyen estado de muestra parcial, crashFreeRate puede sesgarse con ventana que corta sesiones.
