#### 1. [BAD] `init_config` writes without `withFileMutex`
**File**: [`packages/core/src/lib/bootstrap/init-config-tool.ts#L108`](packages/core/src/lib/bootstrap/init-config-tool.ts#L108)

```typescript
const absPath = deps.workspace.resolve(CONFIG_FILENAME);
await writeFileAtomic(
    absPath,
    `${JSON.stringify(config, null, '\t')}\n`,
);
return toolJson({ ok: true, preset: derived.preset, config, … });
```

**Problem**: durable write through `writeFileAtomic` (correct), but **no `withFileMutex`** around it. Two concurrent `init_config` calls can read the same baseline, mutate separately, and the last-writer-wins overwrites whichever side lost. **Rule 4 violation.**
**Impact**: lost or stale `mcp-vertex.config.json` under boot race; corrupts the host's plugin roster and can silently disable plugins.
**Resolution Track**: Untriaged → candidate `x00183-s1-fix-init-config-mutex`.
