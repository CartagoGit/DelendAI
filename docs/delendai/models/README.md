# Agents and models

One page per agent this project uses, generated by
`delendai agents show <id> --write`. Each page is built from the agent's
public catalogue entry and from what the agent says about itself when
greeted over the Agent Client Protocol: its version, how it logs in,
what a prompt may carry and whether it resumes sessions. Nothing on a
page is text delendai keeps about a vendor.

A page records the version it was written for and is rewritten when that
version or the agent's declaration changes. Notes written between the
`delendai:person` markers survive every rewrite. A page without the
generated marker is yours and is never replaced.

Where the agents come from:

- the public [Agent Client Protocol registry](https://agentclientprotocol.com/registry),
  read in layers (configured sources, this machine's copy, the snapshot
  shipped with delendai);
- `agents[]` in `delendai.config.json` or your own file
  (`delendai agents add`);
- what this machine shows: executables on PATH, global packages and IDE
  extensions (`delendai agents list`).
