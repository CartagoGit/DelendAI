# @delendai/self-learning

Opt-in per-project learning store for @delendai/core: accumulates observations the runtime already produces and answers what this project has taught us, without new instrumentation.

## Use

Published as `@delendai/self-learning`. Import from the package root or from `@delendai/self-learning/public`; see `AGENT.md` in this folder for the generated purpose, entry points and dependencies.

## Develop

```sh
bun run --cwd plugins/self-learning test
bun run --cwd plugins/self-learning build
```
