# @delendai/framework-knowledge

Opt-in framework-version knowledge plugin for @delendai/core: resolves what the project's installed framework version allows, recommends and forbids before an agent writes code.

## Use

Published as `@delendai/framework-knowledge`. Import from the package root or from `@delendai/framework-knowledge/public`; see `AGENT.md` in this folder for the generated purpose, entry points and dependencies.

## Develop

```sh
bun run --cwd plugins/framework-knowledge test
bun run --cwd plugins/framework-knowledge build
```
