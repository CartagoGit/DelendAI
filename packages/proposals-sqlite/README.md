# @delendai/proposals-sqlite

SQLite operational truth for the @delendai/proposals plugin (q00022, x00510).

## Use

Published as `@delendai/proposals-sqlite`. Import from the package root or from `@delendai/proposals-sqlite/public`; see `AGENT.md` in this folder for the generated purpose, entry points and dependencies.

## Develop

```sh
bun run --cwd packages/proposals-sqlite test
bun run --cwd packages/proposals-sqlite build
```
