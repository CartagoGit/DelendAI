# @delendai/sqlite

The one cross-runtime SQLite loader for delendai: `bun:sqlite` under Bun, `node:sqlite` behind the same Database shape under Node 22.5+.

## Use

Published as `@delendai/sqlite`. Import from the package root or from `@delendai/sqlite/public`; see `AGENT.md` in this folder for the generated purpose, entry points and dependencies.

## Develop

```sh
bun run --cwd packages/sqlite test
bun run --cwd packages/sqlite build
```
