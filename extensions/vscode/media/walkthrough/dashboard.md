# Open the Dashboard

The **Provider Dashboard** is your control center for model providers
and usage tracking:

- **Provider status** — which AI providers are healthy, paused, or unreachable
- **Routing decisions** — how the orchestrator scores and routes tasks
- **Usage metrics** — token spend by provider, plugin, and agent

## Actions

From the dashboard you can:
- Refresh provider healthchecks
- Pause or resume individual providers
- View detailed usage reports
- Clear usage logs
